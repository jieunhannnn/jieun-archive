# echo-base-images

Echo 캐릭터 **베이스 이미지 3장** (Image Starter 툴의 기준 모델시트).

이 저장소는 툴이 참조할 이미지 호스팅 용도로만 공개돼 있다.
프롬프트·바이블·가이드 등 나머지 작업 자료는 **비공개 저장소**에서 관리한다.

| 파일 | 내용 |
| --- | --- |
| `base/echo-base-front.png` | 정면 서있는 기본 포즈 |
| `base/echo-base-run.png` | 달리는 포즈 |
| `base/echo-base-cheer.png` | 눈 감고 웃는 응원 포즈 |
